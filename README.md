# ScoreX Pro

A responsive live-sports information website starter for Cricket, Football and Tennis.

## Included
- `index.html` — public sports dashboard
- `admin.html` — non-betting admin demo
- `style.css` — responsive dark/neon UI
- `app.js` — demo match cards
- `admin.js` — demo user management

## Make it truly live
The included scores are demo data. For real-time scores, connect a licensed sports-data API through a server/backend. Keep API secrets on the server and cache/rate-limit requests.

## Deploy
This static demo can be hosted on GitHub Pages, Netlify or Vercel. For a real admin login and database, use a backend/database service and server-side authentication.

## Safety
This project intentionally excludes wagering, casino betting, betting wallets, gambling credits/points, and client betting balances.
